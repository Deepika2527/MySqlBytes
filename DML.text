Insert:
Insert can be doen in 3 ways
1. to all columns:
    syntax: 
       insert into tablename values(v1,v2,v3,v4.....vn)
    example:
        insert into student values(101,"Anu','anu@gamil.com','pfs');


2. to few columns:
   synatx:
        insert into tablename(c1,c2,c3,...cn)values(v1,v2,v3...,vn)
   example:
        insert into student(sid,s_name,s_email,s_course) values(102,'Radha','radha@gmail.com','jsf')

3. from one table to another table

   synatx:
        insert into table_name select * from, another_table;
    example:
        insert into student_copy select * from student;
        
-----------------------------------------------------------------------------------------------------------
2. Update:

  syntx:
        update table_name set c1=v1,c2=v2,.... where condtion;
  examples:
        update student_info set s_email = 'newemail' where id = 101;
        update student_info set semail='newvalue',sname = 'newvalue' where id= 101;
--------------------------------------------------------------------------------------------------------
3. delete:
synatx:
    delete from table_name where condtion;
examples:
    delet from student_info wheredept_name is null;
